# Бесплатный хостинг — что реально работает

Музыкальному боту нужны **Node.js + ffmpeg + yt-dlp**.  
Из‑за этого «вечный бесплатный VPS» почти не существует (Oracle для Беларуси недоступен).

## Лучший вариант «прямо сейчас» (бесплатно)

### [Bot-Hosting.net](https://bot-hosting.net/)

- Бесплатно, без карты  
- Бот не засыпает сам по себе  
- Нужно **обновлять бесплатный сервер раз в 4 дня** в панели  
- Загрузка файлов через веб-панель или GitHub  

**Минус:** на бесплатном тарифе иногда нет `ffmpeg`/`yt-dlp`. Если музыка не играет — смотри логи; тогда нужен другой хост.

### Как залить бота (10 минут)

1. Зайди на https://bot-hosting.net/ → **Start for free** (обычно вход через Discord).
2. Создай бесплатный сервер (Node.js).
3. В File Manager загрузи архив `discord-music-bot-upload.zip` (без `.env` и `node_modules`) и распакуй в корень.
4. В **Startup / Environment** добавь переменные из твоего локального `.env`:
   - `DISCORD_TOKEN`
   - `CLIENT_ID`
   - `GUILD_ID`
5. В консоли сервера:
   ```bash
   npm install --omit=dev
   npm run deploy-commands
   ```
6. Startup command:
   ```bash
   node src/index.js
   ```
7. Start сервер. В Discord бот должен стать онлайн.

Проверка ffmpeg на хосте:
```bash
ffmpeg -version
yt-dlp --version
```
Если команд нет — этот бесплатный сервер для музыки не подойдёт.

## Запасной вариант (почти бесплатно на старте)

### [Railway](https://railway.app/)

- Деплой из GitHub + наш `Dockerfile` (там уже есть ffmpeg и yt-dlp)  
- Обычно дают trial-кредит (~$5) — хватает на несколько недель  
- Потом либо платить ~$5/мес, либо бот остановится  

Это самый надёжный «бесплатно на время» вариант именно для **музыкального** бота.
